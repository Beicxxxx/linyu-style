## 📖 核心心智 (Mindset)

**`linyu-style`** 是专为 AI Agent（Antigravity、Cursor、Claude、ChatGPT 等）打造的中文互联网亚文化现象级语言风格 Skill。

直接将本项目克隆或放入全局/工作区技能目录：

